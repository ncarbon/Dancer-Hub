# Dance style demos

Drop a short looping clip for each style here. Filenames match `DanceStyleProfile.id`:

| File | Style |
| --- | --- |
| `hustle.mp4` | Latin Hustle |
| `bachata.mp4` | Bachata |
| `salsa.mp4` | Salsa |
| `kizomba.mp4` | Kizomba |
| `reggaeton.mp4` | Reggaeton |
| `samba.mp4` | Samba |
| `hip-hop.mp4` | Hip Hop |
| `jazz.mp4` | Jazz |
| `ballroom.mp4` | Ballroom |
| `ballet.mp4` | Ballet |
| `contemporary.mp4` | Contemporary |

Tips:
- Prefer **3–6s** muted MP4 (or WebM); GIF also works if you set `demoUrl` to `.gif`
- One clear basic is enough — footwork readable on a phone
- Optional poster: `hustle.jpg` + set `demoPosterUrl: '/demos/hustle.jpg'` in `danceStyles.ts`
- Optional credit: set `demoCredit` on that style

Until a file exists, the lookup card shows a “Demo soon” placeholder with the count.
